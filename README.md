# Pabel López · Portafolio

Fotografía, video, diseño gráfico y páginas web. Sitio bilingüe (español / inglés).

Hecho con HTML, CSS y JavaScript, sin dependencias. Para verlo en tu computadora, abre `index.html` en el navegador.

- `index.html`: página principal (portada, proyectos, servicios, sobre mí y contacto).
- `caso.html?p=esperanza` y `caso.html?p=love`: casos de estudio. Los textos están en `caso.js`.
- `Imagenes/`: fotos del sitio.
- El formulario de contacto usa Formspree. Cambia `TU_ID_DE_FORMSPREE` en `index.html` por tu código.
